# Zomato Restaurant Analysis Using Microsoft Excel

## Project Overview
This project focuses on analyzing restaurant data from Zomato using Microsoft Excel to understand restaurant performance, customer ratings, popularity, pricing, cuisine preferences, and service availability. The report provides insights into the restaurant landscape through data cleaning, analysis, categorization, and visualization.

## Objectives
- Analyze restaurant ratings and customer reviews.
- Identify highly rated and popular restaurants.
- Explore average cost for two and restaurant price categories.
- Analyze restaurant types and cuisine preferences.
- Understand restaurant distribution across different locations.
- Examine online ordering and table booking availability.
- Identify patterns and insights from restaurant data.

## Analysis Performed
- Restaurant rating analysis
- Restaurant popularity analysis
- Cost analysis
- Cuisine and restaurant type analysis
- Area-wise restaurant analysis
- Online order availability analysis
- Table booking analysis
- Restaurant categorization based on ratings, popularity, and cost

## Tools & Techniques
- Microsoft Excel
- Data cleaning and preprocessing
- Excel formulas and functions
- Data categorization
- Data analysis
- Charts and data visualization

## Key Insights
The analysis helps understand the relationship between restaurant ratings, popularity, pricing, cuisine variety, and service availability. It also provides a better understanding of customer preferences and the distribution of restaurants across different areas.

## Project Outcome
This project demonstrates practical Excel skills in data cleaning, data analysis, categorization, and visualization while transforming raw restaurant data into meaningful information for business understanding and decision-making.
